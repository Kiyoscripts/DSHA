DSHA 0.1.5-rc1 official release, maintained and published by contributor @ym2025szz, with thanks to original author @qiannianhuanxiang and the other contributors. Uses the same accepted APKs as GitHub Latest, version code 116.
New dsh 0.1.5-rc.1: supports DeepSeek-V41-Flash and keeps V4 model options. Image, text attachments, and read tools were exercised in real calls.
Files and mobile experience: Markdown, HTML, PDF, image, code, and long-text preview, with scrolling and code copy. Tab close “×” is centered on the right. Keyboard avoidance, Enter-for-newline, tooltips, image drafts, and reading-position restore are improved.
Startup and install: Ubuntu / dsh offline packages are split, unchanged web scripts are reused, and first-run native extension cache failure is fixed. On Android 16, start-to-auth was 3.43–3.66 seconds; full cold-environment verification was about 19.3 seconds.
Overlay updates: the same Ubuntu base updates only the managed runtime. Personal directories, sessions, config, and third-party plugins stay in place. A base-environment change protects data first, then rebuilds. Automatic backup by launch count and full-directory scans at startup are removed. Manual backup and rollback remain.
Errors and maintenance: startup stages, actual plugin errors, exit codes, and log download. Waiting continues after 60 seconds. Independent safe start. Web PIDs are verified. Terminals and background tasks are reclaimed before maintenance.
Preview-era capabilities continue: dual editions, plugin install/import/export/enable/update/rollback, background APK download and verification, wireless ADB, Shizuku, LAN, and PTY, plus a tighter device-command whitelist.
Compared with the previous published rc1.4 preview, dsh moved from 0.1.2-rc.1 to 0.1.5-rc.1. The standard APK is about 17.3% smaller and the compatibility APK about 12.7% smaller.
Keep a manual backup before upgrading. Earlier published v1.2 preview environments used base 9; moving to this base 10 needs data protection and a rebuild. A local alpha.2 same-base partial update took about 7.45 seconds.
This Android 16 round checked models, attachments, tools, WebView/Gecko, file preview, startup, updates, terminals, plugins, and backups. Each edition has 330 unit tests with no failures. Android 6/7 and real 16 KB page kernels still need extra device tests. This is not a claim for every device.
